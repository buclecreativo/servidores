Objetivo de aprendizaje

¿Qué vas a lograr?

Comprender y aplicar los conceptos fundamentales sobre servidores domésticos, redes, servicios, seguridad y mantenimiento, analizando situaciones reales y tomando decisiones fundamentadas sobre hardware, software y configuración, desarrollando actitudes de responsabilidad, perseverancia y ética digital, mediante la exploración guiada, el análisis de casos y la resolución de retos prácticos, para diseñar y mantener un servidor doméstico seguro, funcional y sostenible que responda a necesidades reales de tu entorno.

Este taller te acompañará paso a paso para que puedas responder estas preguntas con criterio técnico y conciencia de las implicaciones de seguridad y mantenimiento.

Desarrollo

Conceptos fundamentales

Explora los niveles de aprendizaje: fundamentos, comprensión, aplicación, análisis y transferencia.

🧱 Nivel 1 — Fundamentos: ¿qué es un servidor?

Un servidor es un ordenador o programa que proporciona servicios, datos o recursos a otros dispositivos llamados clientes. Por ejemplo, cuando abres una página web, tu navegador actúa como cliente y solicita información a un servidor web.

Hardware y software

El hardware son los componentes físicos: procesador, memoria RAM, discos, tarjeta de red. El software son los programas y aplicaciones que se ejecutan, incluido el sistema operativo (Windows, Linux) que administra los recursos.

Servidor dedicado y centro de datos

Un servidor dedicado es un equipo o instancia destinada principalmente a ejecutar servicios de servidor, no a usarse como ordenador personal. Un centro de datos es una instalación que alberga numerosos sistemas informáticos, equipos de red, almacenamiento y sistemas de alimentación y refrigeración.

Analogía: un servidor es como una biblioteca. Los clientes (lectores) solicitan libros (datos o servicios) y la biblioteca los proporciona. El hardware son los estantes y el edificio; el software es el sistema de catalogación y préstamo.

🔍 Explora

Identifica en tu entorno tres dispositivos que actúen como clientes (teléfono, laptop, tablet) y piensa qué servicio consumen de un servidor (web, correo, video, archivos). Anota tus observaciones.

🔗 Nivel 2 — Comprensión: redes y conectividad

Para que un servidor funcione, necesita comunicarse. Aquí entran los conceptos de red.

Red local (LAN)

Una red local (LAN) conecta dispositivos dentro de un área limitada: una vivienda, una oficina o un centro educativo. Es el entorno típico de un servidor doméstico.

Dirección IP

Una dirección IP es una dirección numérica que identifica una interfaz de red y dirige comunicaciones. IPv4 usa formatos como 192.168.1.20; IPv6 usa un formato diferente. Existen IP privadas (usadas dentro de redes privadas, con rangos como 10.x, 172.16–172.31, 192.168.x) y IP públicas (identifican una conexión en Internet).

DNS y dominio

El DNS es el sistema que permite encontrar direcciones IP a partir de nombres de dominio como ejemplo.com. Un dominio es el nombre legible que identifica un servicio o sitio en Internet.

Puerto, router, Ethernet, Wi-Fi y VPN

  • Puerto: número que identifica un punto de comunicación de una aplicación o servicio. Los servidores web suelen usar los puertos TCP 80 y 443.
  • Router: dispositivo que dirige el tráfico entre redes. En casa conecta la red local con Internet.
  • Ethernet: tecnología de red cableada que proporciona una conexión estable entre un servidor y el router o un conmutador.
  • Wi-Fi: tecnología de red inalámbrica que permite conectar dispositivos sin cable.
  • VPN: red privada virtual que crea una conexión protegida a través de otra red. Útil para acceder de forma más segura a servicios de una red doméstica.
Analogía: la dirección IP es como la dirección de una casa; el puerto es como el número de apartamento; el DNS es como la guía telefónica que traduce nombres a direcciones; el router es como el portero que dirige a cada visitante a la casa correcta.

Si tu router tiene la IP pública 190.15.20.30 y tu servidor tiene la IP privada 192.168.1.50, ¿qué crees que ocurre cuando alguien desde Internet intenta acceder a tu servidor? ¿Qué papel juega el router?

⚙️ Nivel 3 — Aplicación: servicios y recursos

Los servidores ofrecen servicios concretos. Estos son los más relevantes para un servidor doméstico.

Servicios y aplicaciones

  • Servidor web: entrega páginas y otros recursos mediante protocolos como HTTP y HTTPS. HTTPS protege la comunicación mediante cifrado TLS.
  • Base de datos: sistema que permite almacenar, organizar, consultar y modificar información estructurada.
  • Servidor multimedia: organiza y distribuye contenido audiovisual a dispositivos clientes.
  • Servidor de archivos: permite almacenar y compartir archivos entre usuarios y dispositivos.
  • Contenedor: entorno aislado que ejecuta una aplicación con sus dependencias utilizando funciones del sistema operativo. Docker es una herramienta conocida.
  • Máquina virtual: ordenador simulado por software que ejecuta su propio sistema operativo dentro de otro sistema anfitrión.
  • Virtualización: tecnología que permite ejecutar varias máquinas virtuales en un mismo equipo físico.
  • Interfaz web: pantalla de administración o aplicación accesible mediante navegador.
  • Transcodificación: conversión de un archivo multimedia a otro formato, resolución o tasa de bits para facilitar su reproducción.

Recursos y rendimiento

  • CPU o procesador: ejecuta instrucciones y realiza cálculos. Su capacidad influye en el rendimiento.
  • RAM: memoria de trabajo del sistema operativo y las aplicaciones.
  • SSD: unidad basada en memoria flash, con tiempos de acceso y velocidades superiores a los discos duros tradicionales.
  • HDD: disco duro mecánico, con gran capacidad a coste relativamente bajo.
  • Ancho de banda: capacidad de una conexión para transportar datos por unidad de tiempo (Mbps o Gbps).
  • Latencia: tiempo que tarda una comunicación en viajar entre dos puntos y recibir respuesta. Una latencia baja es importante para juegos y aplicaciones interactivas.
  • Uptime: tiempo durante el que un sistema o servicio permanece funcionando y disponible.

🔍 Explora

Para el servicio que imaginaste al inicio del taller, haz una lista de los recursos que necesitarías: ¿cuánta RAM? ¿qué tipo de almacenamiento (SSD o HDD)? ¿qué ancho de banda? ¿qué latencia sería aceptable? Justifica brevemente.

🛡️ Nivel 4 — Análisis: seguridad y mantenimiento

La seguridad no es un añadido final: es parte del funcionamiento normal de cualquier servidor.

Conceptos de seguridad

  • Cortafuegos (firewall): sistema que filtra las conexiones de red según reglas definidas para permitir o bloquear tráfico.
  • Autenticación: proceso mediante el cual un sistema comprueba la identidad de un usuario o dispositivo.
  • Autorización: proceso que determina qué acciones puede realizar un usuario una vez identificado.
  • Permisos: reglas que determinan quién puede leer, modificar, ejecutar o administrar recursos.
  • Actualización de seguridad: modificación de software que corrige vulnerabilidades u otros problemas.
  • Copia de seguridad (backup): copia de los datos que permite recuperarlos si los originales se pierden, dañan o eliminan.
  • Restauración: proceso de recuperar archivos o sistemas a partir de una copia de seguridad.
  • Cifrado: técnica que transforma la información para que solo pueda leerse con los medios de descifrado adecuados.
  • CGNAT: mecanismo mediante el cual un proveedor de Internet comparte una dirección IPv4 pública entre varios clientes. Puede impedir que una red doméstica reciba conexiones entrantes mediante redirección de puertos convencional.

Recomendaciones finales de seguridad

  1. Mantén el sistema actualizado (sistema operativo y aplicaciones).
  2. Utiliza contraseñas únicas y robustas. Activa la autenticación multifactor cuando esté disponible.
  3. Limita los accesos. Crea cuentas específicas y concede solo los permisos necesarios.
  4. Configura el cortafuegos. Permite únicamente los puertos y conexiones que necesites.
  5. No expongas servicios sin necesidad. Para acceder desde fuera de casa, considera primero una VPN bien configurada.
  6. Protege las copias de seguridad. Mantén al menos una copia independiente del equipo principal y prueba que puedes restaurarla.
  7. Supervisa el almacenamiento. Comprueba periódicamente el espacio disponible y el estado de los discos.
  8. Documenta los cambios. Anota las configuraciones importantes para poder solucionar problemas y reconstruir el sistema.
  9. Planifica las actualizaciones y reinicios. Ten en cuenta que pueden provocar interrupciones temporales.
  10. Respeta la privacidad y los derechos de uso. Protege los datos de otras personas y utiliza el contenido multimedia de acuerdo con las licencias y la legislación aplicable.
Errores frecuentes al comenzar:
  • Instalar demasiados programas antes de aprender a administrar uno.
  • Usar el usuario administrador para todas las tareas cotidianas.
  • Compartir carpetas sin revisar permisos.
  • Abrir puertos del router sin comprender qué servicio queda expuesto.
  • Confiar en una única copia de seguridad almacenada en el mismo disco.
  • Ignorar los registros de errores y las advertencias de almacenamiento.
  • Instalar programas de procedencia desconocida.
  • No probar las restauraciones de las copias de seguridad.
  • Pensar que tener un servidor encendido equivale a tener un servicio siempre disponible.
Regla fundamental: primero consigue que el servidor funcione de forma segura en tu red local; después, cuando comprendas su configuración, estudia cómo permitir accesos externos si realmente los necesitas.

🚀 Nivel 5 — Transferencia: elegir tu primer servidor

No existe un servidor perfecto para todos. La elección depende de los servicios que quieras ofrecer, tu presupuesto y el tiempo que puedas dedicar a mantenerlo.

🖥️

Aprovechar un ordenador antiguo

Empieza con un servicio ligero: compartir archivos o alojar una página web de prueba. Antes de reutilizarlo, comprueba su estado, el almacenamiento disponible y el consumo eléctrico.

⚡

Servidor doméstico de bajo consumo

Considera un mini-PC eficiente, especialmente si planeas mantener varios servicios funcionando durante muchas horas al día. Prioriza la eficiencia energética.

🐧

Aprender administración de sistemas

Instala Linux en un equipo de pruebas o en una máquina virtual. Practica con usuarios, permisos, servicios, redes y registros antes de administrar un equipo importante.

💾

Guardar información importante

Prioriza la fiabilidad del almacenamiento, las copias de seguridad independientes y la facilidad de recuperación. Un servidor no sustituye por sí solo a un sistema de respaldo.

Consumo eléctrico

Si vas a dejar el ordenador encendido durante muchas horas, conviene estimar su consumo. La fórmula básica es:

Energía (kWh) = (Potencia (W) × Horas) / 1000

Por ejemplo, si un servidor consume una media de 40 W y permanece encendido 24 horas al día:
(40 × 24) / 1000 = 0,96 kWh/día
En 30 días serían aproximadamente 28,8 kWh. El coste se calcula multiplicando los kWh consumidos por el precio que pagas por cada kWh.

La potencia real varía según la carga del procesador, los discos, la fuente de alimentación y los periféricos. Un medidor de consumo ayuda a obtener una estimación más realista.

Rutina de mantenimiento recomendada

  • Semanal: comprobar que los servicios principales funcionan y que los archivos importantes están disponibles.
  • Semanal: revisar alertas de almacenamiento, errores repetidos o fallos en copias de seguridad.
  • Mensual: instalar actualizaciones planificadas y revisar aplicaciones que ya no utilizas.
  • Mensual: comprobar espacio en disco, uso de RAM y carga del procesador.
  • Mensual: probar la restauración de algunos archivos desde una copia de seguridad.
  • Cada 3–6 meses: revisar ventilación, limpiar polvo con el equipo apagado y comprobar cables.
  • Cada 3–6 meses: revisar cuentas, permisos, servicios publicados y reglas del cortafuegos.

La frecuencia exacta dependerá de la importancia del servicio, la exposición a Internet y la cantidad de datos almacenados. Un servidor que presta servicios a otras personas necesita una supervisión más rigurosa que uno usado únicamente para aprender.

Ruta de aprendizaje recomendada

  1. Fundamentos: identificar la IP del servidor, iniciar servicios y acceder desde otro dispositivo de la red.
  2. Administración básica: practicar con usuarios, permisos, actualizaciones, registros, espacio en disco y reinicios controlados.
  3. Automatización: programar copias de seguridad, gestionar servicios y utilizar contenedores con Docker.
  4. Acceso remoto seguro: estudiar VPN, certificados TLS, autenticación multifactor y las implicaciones de publicar servicios en Internet.
  5. Supervisión y recuperación: interpretar registros, controlar consumo de recursos, detectar fallos y recuperar el servicio tras un incidente.

Reto integrador

Diseña tu servidor doméstico seguro

Aplica todo lo aprendido en un desafío auténtico.

📋 Contexto

Tu institución educativa quiere montar un pequeño servidor doméstico para compartir recursos educativos (documentos, videos, presentaciones) entre estudiantes y docentes. Te han pedido que diseñes una propuesta técnica que sea segura, funcional y sostenible. El servidor estará en la sala de computación y se conectará a la red local del colegio.

🎯 Objetivo

Diseñar una propuesta completa que incluya:

  • Selección del hardware (reutilizar un equipo existente o mini-PC de bajo consumo).
  • Sistema operativo y servicios a implementar (servidor de archivos, servidor web, etc.).
  • Configuración de red (IP privada, puertos, firewall, VPN si es necesaria).
  • Plan de seguridad (autenticación, autorización, permisos, actualizaciones).
  • Plan de copias de seguridad y restauración.
  • Estimación del consumo eléctrico y rutina de mantenimiento.

📌 ¿Qué debes lograr?

  • Una propuesta escrita (puede ser un documento, presentación o esquema visual) que cubra todos los puntos anteriores.
  • Justificación técnica de cada decisión, usando los conceptos del taller.
  • Identificación de al menos tres errores frecuentes que evitarás y cómo lo harás.
  • Una reflexión sobre las implicaciones éticas y de privacidad del proyecto.

⚠️ Restricciones

  • No puedes asumir acceso a Internet permanente ni servicios en la nube de pago.
  • El presupuesto es limitado: prioriza reutilizar hardware existente.
  • Debes garantizar que el servidor no exponga datos de estudiantes sin autorización.
  • El consumo eléctrico debe ser razonable para un centro educativo.

✅ Criterios de éxito

  • Comprensión: los conceptos técnicos se usan correctamente.
  • Aplicación: las decisiones se conectan con los servicios y recursos disponibles.
  • Funcionalidad: la propuesta es viable en un entorno real.
  • Creatividad: se proponen soluciones propias y adaptadas al contexto.
  • Calidad técnica: se respetan las buenas prácticas de seguridad y mantenimiento.
  • Argumentación: cada decisión está justificada.
  • Ética: se consideran la privacidad y los derechos de uso.
Pista: recuerda la regla fundamental: primero asegura el funcionamiento seguro en la red local; luego evalúa si realmente necesitas acceso externo.
