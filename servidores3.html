Nivel 1 — Fundamentos: La red local (LAN)

¿Qué es una red local?

Una red local (LAN, Local Area Network) es un conjunto de dispositivos conectados entre sí dentro de un área limitada, como una vivienda, una oficina o un centro educativo.

Estos dispositivos pueden compartir archivos, impresoras, conexión a Internet y otros recursos. Por ejemplo, en una casa puedes tener:

  • Un ordenador de sobremesa.
  • Un portátil.
  • Varios teléfonos móviles.
  • Una televisión inteligente.
  • Un router que conecta los dispositivos.

Si todos están conectados a la misma red local, pueden comunicarse entre sí siempre que la configuración de red y los permisos lo permitan.

¿Qué función cumple el router?

El router es el dispositivo que conecta diferentes redes y dirige el tráfico entre ellas. En una vivienda, normalmente conecta la red doméstica con Internet.

Muchos routers domésticos también incorporan otras funciones, como:

  • Punto de acceso Wi-Fi: permite conectar dispositivos inalámbricamente.
  • Servidor DHCP: asigna automáticamente direcciones IP a los dispositivos.
  • Firewall: aplica reglas para controlar determinadas conexiones.
  • Switch integrado: permite conectar varios equipos mediante cables Ethernet.

Estas funciones pueden estar distribuidas en dispositivos diferentes, aunque suelen venir integradas en un mismo aparato doméstico.

🌐 Ejemplo práctico

Si conectas tu PC al router mediante un cable Ethernet y tu teléfono al mismo router por Wi-Fi, ambos pueden comunicarse a través de la red local. Así podrías acceder desde el teléfono a una página web alojada en tu PC.

🏠 Analogía

Una red local es como una casa: todos los dispositivos que están dentro pueden hablar entre ellos. El router sería la puerta principal que conecta la casa con el resto del mundo (Internet).

Nivel 2 — Comprensión: Direcciones IP, DNS y puertos

Dirección IP pública y privada

Una dirección IP (Internet Protocol) es una dirección numérica que permite identificar una interfaz de red y dirigir los datos hacia su destino. Existen dos versiones principales: IPv4 e IPv6. En redes domésticas todavía es muy común encontrar direcciones IPv4.

🏠 Dirección IP privada

Se utiliza dentro de una red privada, como la red de tu hogar. No es directamente enrutable a través de Internet público.

Ejemplos de rangos privados IPv4:

  • 10.0.0.0 – 10.255.255.255
  • 172.16.0.0 – 172.31.255.255
  • 192.168.0.0 – 192.168.255.255

Estas direcciones son ejemplos: las direcciones reales dependen de la configuración del router.

🌍 Dirección IP pública

Identifica el punto de conexión de una red con Internet. Normalmente la asigna el proveedor de servicios de Internet (ISP), aunque existen distintas configuraciones.

Puede ser:

  • Dinámica: cambia con el tiempo.
  • Estática: se contrata o configura de ese modo.

Una dirección IP pública no garantiza por sí sola que puedas acceder a tu servidor desde Internet. También influyen el router, el firewall, las reglas de acceso y las restricciones del proveedor.

Diferencias entre dirección IP privada y pública
Característica IP Privada IP Pública
Alcance habitual Red local (LAN) Internet
Ejemplo 192.168.1.50 203.0.113.10
Asignación Router (DHCP) Proveedor de Internet (ISP)
Acceso directo desde Internet No Sí (con configuración adecuada)

¿Cómo puedes conocer la IP de tu PC?

En Windows:

  1. Abre el menú Inicio.
  2. Escribe cmd y abre el Símbolo del sistema.
  3. Ejecuta el comando:
ipconfig
  1. Busca el adaptador de red que estás utilizando.
  2. Localiza el campo Dirección IPv4.

En Linux:

Puedes abrir una terminal y ejecutar:

ip addr

Busca la dirección correspondiente a la interfaz de red conectada.

Nombre de dominio y DNS

Un nombre de dominio es un nombre fácil de recordar que puede utilizarse para localizar un servicio en una red. Por ejemplo, ejemplo.com es más sencillo de recordar que una dirección IP numérica.

El DNS (Domain Name System) es un sistema que permite consultar qué direcciones IP están asociadas a nombres de dominio y obtener otros registros necesarios para el funcionamiento de los servicios de Internet.

🔄 El proceso simplificado funciona así:
  1. Escribes un dominio en el navegador.
  2. El dispositivo consulta la información DNS, si no está disponible en su caché.
  3. Obtiene la dirección IP correspondiente.
  4. El navegador intenta establecer una conexión con el servidor.

¿Qué es el DNS dinámico (DDNS)?

En algunas conexiones domésticas, la dirección IP pública cambia periódicamente. El DNS dinámico (DDNS) permite actualizar automáticamente la asociación entre un nombre de dominio y la dirección IP actual.

Esta solución puede resultar útil cuando deseas acceder a un servidor doméstico desde fuera de casa. Por ejemplo, podrías utilizar un nombre como miservidor.example.net en lugar de tener que recordar una dirección IP que puede cambiar.

⚠️ Importante

El DDNS no elimina las restricciones del proveedor de Internet ni sustituye la configuración del router y del firewall.

Puertos y protocolos de comunicación

Para que un cliente pueda comunicarse con un servicio concreto, normalmente necesita conocer la dirección del servidor y el puerto en el que está disponible el servicio.

🏢 Analogía

Puedes imaginar la dirección IP como la dirección de un edificio y el puerto como el número de una oficina dentro de ese edificio.

Un puerto de red es un número lógico que permite identificar un servicio o aplicación dentro de una comunicación de red basada en TCP o UDP.

Por ejemplo, un mismo ordenador puede ejecutar un servidor web y un servicio de administración remota. Cada servicio puede utilizar un puerto diferente.

Algunos puertos habituales son:

Puertos y protocolos habituales
Puerto(s) Protocolo o servicio habitual
20 y 21FTP
22SSH / SFTP
25SMTP (correo)
53DNS
80HTTP
443HTTPS
3389Escritorio remoto de Windows (RDP)

Estos son valores habituales, no reglas absolutas: algunos servicios pueden configurarse para utilizar otros puertos.

¿Qué es un protocolo?

Un protocolo de red es un conjunto de reglas que define cómo se comunican los dispositivos. Entre los más importantes para administrar servidores se encuentran:

  • HTTP: permite intercambiar información para servicios web.
  • HTTPS: añade cifrado TLS a la comunicación HTTP.
  • FTP: permite transferir archivos, aunque la versión tradicional no cifra las credenciales ni los datos.
  • SFTP: permite transferir archivos mediante una conexión SSH.
  • SSH: permite administrar sistemas de forma remota mediante una conexión cifrada.
  • SMB: se utiliza habitualmente para compartir archivos e impresoras.
  • DNS: permite consultar información sobre nombres de dominio.

¿Qué es la redirección de puertos?

La redirección de puertos es una regla del router que dirige determinadas conexiones entrantes hacia un dispositivo de la red local.

Por ejemplo, si deseas publicar un servidor web doméstico, podrías configurar una regla para dirigir las conexiones entrantes al puerto 443 del equipo que aloja la página web.

⚠️ Precaución

Esta configuración requiere precaución: abrir un puerto puede exponer un servicio a intentos de conexión desde Internet. Antes de hacerlo, es necesario revisar las actualizaciones, la autenticación y las reglas del firewall.

Para comenzar, es preferible probar los servicios dentro de la red local y publicar un servicio en Internet únicamente cuando sea necesario.

Nivel 3 — Aplicación: Conexión por cable y Wi-Fi

Los dispositivos pueden conectarse a una red local mediante cables o de forma inalámbrica.

🔌 Conexión Ethernet

  • Generalmente estable.
  • Baja latencia.
  • Adecuada para transferir archivos grandes.
  • Recomendada para servidores que funcionan continuamente.

📶 Conexión Wi-Fi

  • Evita instalar cables.
  • Facilita la ubicación de los dispositivos.
  • Puede sufrir interferencias.
  • Su rendimiento depende de la señal y de la congestión.

Ambas tecnologías permiten ejecutar un servidor. La elección depende de la estabilidad, la velocidad y las condiciones de la red.

Si quieres montar un servidor para compartir archivos grandes, transmitir películas o ejecutar un servicio utilizado por varios dispositivos, una conexión Ethernet suele ser una buena elección. Para pruebas sencillas, un servidor conectado por Wi-Fi puede ser suficiente.

💡 Consejo práctico

Si tu servidor va a estar encendido 24/7 y necesita transferir datos constantemente, usa cable Ethernet. Si es para pruebas o uso esporádico, Wi-Fi puede ser suficiente.

Nivel 4 — Análisis: Acceso local y acceso remoto

Un servidor puede ofrecer sus servicios únicamente dentro de una red local o permitir conexiones desde otros lugares.

Acceso local

El acceso local se produce cuando un dispositivo se conecta al servidor desde el mismo equipo o desde la red local.

Por ejemplo, si tu PC servidor tiene la dirección 192.168.1.50 y ejecuta un servidor web en el puerto 8080, podrías acceder desde otro equipo de la misma red utilizando:

http://192.168.1.50:8080

Esta dirección solo funcionará si el servidor escucha en ese puerto, el firewall permite la conexión y ambos dispositivos pueden comunicarse.

Acceso remoto

El acceso remoto permite conectarse a un servidor desde otra red, por ejemplo, desde tu trabajo o cuando estás de viaje.

Existen varias formas de hacerlo:

  • VPN: crea una conexión protegida para acceder a una red privada.
  • SSH: permite administrar remotamente sistemas compatibles.
  • Escritorio remoto: permite controlar gráficamente un equipo.
  • Servicios web publicados: permiten acceder a aplicaciones desde un navegador.
🚫 CGNAT

En algunos casos, el proveedor de Internet utiliza CGNAT, una tecnología que comparte una dirección IPv4 pública entre varios clientes. En ese escenario, la redirección de puertos convencional puede no funcionar. Una VPN con capacidad de acceso remoto o un servicio de conexión intermediaria puede ser una alternativa.

🔒 Recomendación de seguridad

No expongas servicios de administración directamente a Internet sin las medidas de protección adecuadas. Utiliza contraseñas robustas, autenticación adicional cuando esté disponible y software actualizado.

Nivel 5 — Transferencia: Resumen y aplicación real

Para configurar un servidor es importante comprender los siguientes conceptos:

  • Red local (LAN): permite que los dispositivos se comuniquen dentro de un entorno limitado.
  • Dirección IP: identifica una interfaz de red y permite dirigir el tráfico.
  • Dominio y DNS: facilitan la localización de servicios mediante nombres.
  • Puertos: permiten identificar los servicios de red.
  • Protocolos: establecen las reglas de comunicación entre clientes y servidores.
  • Ethernet y Wi-Fi: son dos formas habituales de conectar dispositivos.
  • Acceso local y remoto: determinan desde dónde se puede utilizar el servidor.

Con estos conocimientos ya puedes entender cómo se conectan los dispositivos y qué elementos intervienen cuando accedes a un servicio alojado en tu PC.

🎯 Aplicación real

Imagina que tienes un emprendimiento de diseño gráfico y quieres compartir tus archivos con tus clientes sin usar servicios de terceros. Con lo aprendido, podrías montar un servidor web en tu PC, configurar un DNS dinámico y permitir que tus clientes descarguen sus diseños desde cualquier lugar, con las medidas de seguridad adecuadas.

Desafío final

🏗️ «Mi primer servidor en casa»

Eres el responsable de tecnología de un pequeño emprendimiento familiar. Tu tarea es diseñar la configuración de red y servidor para que todos los dispositivos del negocio puedan comunicarse entre sí y, además, permitir que un cliente externo acceda a un servicio web alojado en el local.

Contexto:

  • El negocio tiene 3 computadoras de escritorio, 2 laptops, 2 teléfonos móviles y una impresora.
  • Necesitan compartir archivos entre todos los dispositivos.
  • Quieren alojar una página web con información del negocio en una de las computadoras.
  • El proveedor de Internet les ha dado una IP pública dinámica.
  • El router del local permite configurar redirección de puertos y tiene firewall integrado.

¿Qué debes lograr?

  • Diseñar un esquema de red local que incluya todos los dispositivos.
  • Asignar direcciones IP privadas coherentes (puedes usar el rango 192.168.1.0/24).
  • Indicar qué puerto usarías para el servidor web y por qué.
  • Explicar cómo configurarías el acceso remoto para que el cliente externo pueda ver la página.
  • Mencionar al menos 3 medidas de seguridad que aplicarías.
  • Justificar si usarías Ethernet o Wi-Fi para el servidor y por qué.

Criterios de éxito

  • Comprensión: Los conceptos de IP, puertos y protocolos se aplican correctamente.
  • Aplicación: La configuración propuesta es coherente y funcional.
  • Creatividad: Se proponen soluciones propias y bien argumentadas.
  • Seguridad: Se incluyen medidas de protección adecuadas.
  • Argumentación: Cada decisión está justificada técnicamente.
  • Buenas prácticas: Se demuestra responsabilidad y ética profesional.
