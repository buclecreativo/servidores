Servidores y Software de Servidor

Objetivo de aprendizaje

¿Qué vas a lograr?

Analizar, seleccionar e implementar diferentes programas y plataformas para convertir un ordenador en servidor, comprendiendo sus fundamentos técnicos, comparando alternativas según necesidades reales y aplicando buenas prácticas de seguridad y administración, mediante el estudio de casos, la experimentación guiada y la resolución de un reto integrador, para desarrollar competencias digitales que te permitan crear soluciones tecnológicas funcionales en tu entorno escolar, personal o emprendedor.

Activación

Un problema cotidiano

Imagina que tienes un ordenador antiguo en casa. Ya no lo usas para estudiar ni para jugar, pero sigue funcionando. Un día piensas: «¿Y si lo convierto en algo útil?». Quieres compartir archivos con tus compañeros de clase, ver películas desde el televisor del salón, alojar la página web del emprendimiento de tu familia o simplemente aprender cómo funciona un servidor real.

El problema es que no sabes por dónde empezar. ¿Qué programa instalar? ¿Cuál es más fácil? ¿Cuál es más seguro? ¿Sirve para lo que necesito? Existen decenas de herramientas, y cada una tiene ventajas, limitaciones y casos de uso específicos.

En este taller vas a descubrir que convertir un ordenador en servidor es más sencillo de lo que parece, pero requiere tomar decisiones informadas. ¿Te atreves a descubrir qué servidor puedes crear con lo que ya tienes?

Nivel 1 — Fundamentos

1 Tres conceptos clave antes de empezar

Antes de elegir un programa, es importante distinguir tres conceptos fundamentales:

Sistema operativo

Administra el ordenador y permite ejecutar los programas. Ejemplos: Windows Server, Ubuntu Server y Debian.

Software de servidor

Proporciona un servicio específico, como alojar páginas web o compartir archivos.

Plataforma de administración

Facilita la instalación y gestión de varios servicios, a menudo mediante una interfaz gráfica o web.

Ejemplo: Puedes instalar Ubuntu Server en tu PC, utilizar Docker para ejecutar aplicaciones y administrar algunos servicios mediante una interfaz web. También puedes utilizar Windows e instalar un servidor web compatible con ese sistema operativo. La elección depende de lo que quieras hacer, de los recursos de tu equipo y de tu experiencia.

Nivel 2 — Comprensión

2 XAMPP: desarrollo web local

¿Qué es? XAMPP es un paquete de software que facilita la instalación de un entorno de desarrollo web. Incluye Apache, MariaDB, PHP y otras herramientas.

¿Cómo funciona? Instalas un solo programa y obtienes todos los componentes necesarios para probar páginas web y aplicaciones PHP en tu propio ordenador, sin necesidad de configurar cada componente por separado.

Analogía: XAMPP es como un kit de herramientas completo para un electricista. En lugar de comprar cables, interruptores y enchufes por separado, abres la caja y tienes todo listo para empezar a trabajar.

¿Qué puedes hacer con XAMPP?

  • Crear páginas web y probarlas desde el navegador.
  • Desarrollar aplicaciones con PHP.
  • Utilizar bases de datos MariaDB.
  • Probar proyectos web antes de publicarlos.
  • Permitir el acceso a una página de prueba desde otros dispositivos de tu red, si configuras correctamente el servicio.

Ventajas

  • Instalación relativamente sencilla.
  • Panel de control gráfico.
  • Incluye varias herramientas de desarrollo.
  • Adecuado para aprender y realizar pruebas.

Desventajas

  • No es la mejor opción como plataforma predeterminada para un servidor público de producción.
  • Una configuración insegura puede exponer bases de datos y herramientas administrativas.
  • Para proyectos profesionales conviene configurar los componentes individualmente o utilizar una plataforma de despliegue apropiada.
Ejemplo práctico: Instala XAMPP en Windows, inicia Apache y coloca los archivos de tu página en el directorio htdocs. Después, abre http://localhost/ en el navegador para probarla.
Error frecuente: Dejar XAMPP accesible desde Internet sin contraseñas ni configuraciones de seguridad. Esto puede exponer tu base de datos y permitir accesos no autorizados. Siempre configura permisos y contraseñas antes de exponer cualquier servicio.

3 CasaOS: administrar aplicaciones desde una interfaz web

¿Qué es? CasaOS es una plataforma de administración orientada a servidores domésticos. Permite gestionar aplicaciones, almacenamiento y otros recursos mediante una interfaz web.

¿Cómo funciona? Instalas CasaOS en tu PC y accedes desde el navegador a un panel visual donde puedes instalar, configurar y administrar aplicaciones sin usar la terminal.

Analogía: CasaOS es como el escritorio de tu teléfono inteligente: tienes iconos para cada aplicación y las gestionas con toques, sin necesidad de escribir comandos.

¿Qué puedes hacer con CasaOS?

  • Instalar aplicaciones compatibles.
  • Administrar servicios domésticos desde el navegador.
  • Organizar aplicaciones y almacenamiento.
  • Crear un entorno para servicios multimedia y herramientas personales.
  • Simplificar algunas tareas habituales de administración.

Ventajas

  • Interfaz visual intuitiva.
  • Pensado para proyectos domésticos.
  • Facilita la gestión de múltiples aplicaciones.
  • Puede resultar más accesible para principiantes que una administración basada únicamente en comandos.

Desventajas

  • Necesitas comprobar la compatibilidad con el sistema operativo y el hardware.
  • La instalación y el mantenimiento siguen requiriendo conocimientos básicos.
  • No elimina la necesidad de configurar permisos, actualizaciones y medidas de seguridad.
  • La disponibilidad de aplicaciones depende del catálogo y del método de instalación.
Ejemplo práctico: Puedes instalar CasaOS en un PC dedicado y utilizarlo como punto central para gestionar aplicaciones de tu red doméstica.

4 Docker: ejecutar aplicaciones en contenedores

¿Qué es? Docker es una plataforma que permite empaquetar y ejecutar aplicaciones en contenedores. Un contenedor incluye la aplicación y sus dependencias, lo que facilita su instalación y despliegue en entornos compatibles.

¿Cómo funciona? A diferencia de una máquina virtual tradicional, un contenedor normalmente comparte el kernel del sistema operativo anfitrión.

Analogía: Docker es como una caja de herramientas portátil: cada contenedor tiene todo lo necesario para funcionar, y puedes llevarlo a cualquier taller compatible sin preocuparte por las herramientas del lugar.

¿Qué puedes hacer con Docker?

  • Ejecutar varias aplicaciones en un mismo servidor.
  • Separar los entornos de diferentes servicios.
  • Reproducir configuraciones de forma más consistente.
  • Actualizar o sustituir aplicaciones con mayor facilidad.
  • Ejecutar servicios como Jellyfin, servidores web y bases de datos mediante imágenes compatibles.
  • Facilitar la instalación y administración de aplicaciones.
  • Permitir aislar servicios entre sí, aunque no equivale a una garantía absoluta de seguridad.
  • Favorecer la portabilidad entre entornos compatibles.
  • Contar con un amplio ecosistema de imágenes y herramientas.

Ventajas

  • Facilita la instalación y administración de aplicaciones.
  • Permite aislar servicios entre sí, aunque no equivale a una garantía absoluta de seguridad.
  • Favorece la portabilidad entre entornos compatibles.
  • Cuenta con un amplio ecosistema de imágenes y herramientas.

Desventajas

  • Requiere aprender conceptos como imágenes, contenedores, volúmenes y redes.
  • Los datos importantes deben almacenarse de forma persistente.
  • Una configuración incorrecta de permisos o puertos puede exponer servicios.
  • La instalación y las condiciones de uso de Docker Desktop difieren de las de Docker Engine en Linux.
Ejemplo práctico: Puedes utilizar Docker Compose para definir una aplicación y sus servicios relacionados en un archivo de configuración, y después iniciarlos conjuntamente.
Error frecuente: No almacenar datos de forma persistente. Si eliminas un contenedor sin volúmenes configurados, pierdes la información. Siempre utiliza volúmenes para datos importantes.

5 Jellyfin: servidor multimedia personal

¿Qué es? Jellyfin es un sistema multimedia gratuito y de código abierto que permite organizar y transmitir contenido personal desde un servidor a diferentes dispositivos.

¿Cómo funciona? Instalas Jellyfin en tu PC, añades carpetas con tus películas, series, música y vídeos, y accedes desde cualquier dispositivo conectado a tu red mediante un navegador o una aplicación compatible.

Analogía: Jellyfin es como tener tu propio cine en casa: organizas tus películas en estanterías digitales y las reproduces en cualquier pantalla de tu hogar.

¿Qué puedes hacer con Jellyfin?

  • Organizar una biblioteca multimedia.
  • Reproducir contenido desde un navegador o una aplicación compatible.
  • Crear usuarios y administrar el acceso a las bibliotecas.
  • Consultar información y carátulas del contenido.
  • Transmitir archivos a televisores, teléfonos y otros dispositivos compatibles.

Ventajas

  • Gratuito y de código abierto.
  • Permite mantener el control sobre el servidor y la biblioteca.
  • Cuenta con opciones de instalación para Windows, Linux y contenedores.
  • No exige una suscripción premium para desbloquear funciones del servidor.

Desventajas

  • Necesita suficiente almacenamiento para la biblioteca multimedia.
  • La transcodificación puede exigir recursos considerables.
  • Algunos dispositivos pueden necesitar aplicaciones específicas o formatos compatibles.
  • La configuración de acceso remoto requiere medidas de seguridad adicionales.
Ejemplo práctico: Instala Jellyfin en tu PC, añade una carpeta con tus vídeos y accede desde otro dispositivo conectado a tu red.

Explora

Si tienes un ordenador con Linux, investiga cómo instalar Jellyfin desde la terminal. Si usas Windows, busca el instalador oficial. ¿Qué diferencia encuentras entre ambos métodos?

6 File Browser y Samba: compartir y administrar archivos

File Browser proporciona una interfaz web para navegar por carpetas y administrar archivos. Puede ser útil si quieres acceder a documentos desde distintos dispositivos utilizando un navegador.

Samba implementa servicios de archivos e impresión compatibles con SMB, lo que facilita compartir recursos entre sistemas Linux y equipos Windows.

¿Cuál conviene utilizar? File Browser es una buena alternativa cuando prefieres administrar archivos desde una interfaz web. Samba resulta más adecuado cuando quieres que las carpetas compartidas aparezcan como recursos de red en el explorador de archivos de tus ordenadores.

Ventajas de estas soluciones

  • Permiten centralizar documentos.
  • Facilitan el acceso desde varios dispositivos.
  • Pueden aprovechar discos duros que ya tienes.
  • Ayudan a organizar el almacenamiento doméstico.

Desventajas

  • Debes configurar correctamente los permisos de acceso.
  • Es necesario evitar que usuarios no autorizados accedan a los archivos.
  • El almacenamiento compartido no sustituye a una copia de seguridad.
Ejemplo práctico: Instala Samba en un PC con Linux y crea una carpeta compartida para que otros equipos de tu red puedan guardar y consultar documentos.
Error frecuente: Compartir carpetas sin contraseñas ni permisos adecuados. Cualquier persona en la red podría acceder a tus archivos. Siempre configura usuarios y permisos específicos.

7 Apache y Nginx: alojar páginas web

Apache HTTP Server es un servidor web ampliamente utilizado que permite entregar páginas y ejecutar configuraciones para diferentes tipos de sitios web. Resulta útil para aprender alojamiento web y desplegar aplicaciones compatibles.

Nginx es un servidor web y proxy inverso que también permite alojar páginas web, con un enfoque en el rendimiento y la eficiencia.

¿Cómo funciona? Instalas el servidor, configuras los archivos del sitio en el directorio correspondiente y accedes desde un navegador mediante la dirección IP o el dominio configurado.

Analogía: Apache y Nginx son como los recepcionistas de un edificio: reciben las solicitudes de los visitantes (usuarios) y les entregan la información que necesitan (páginas web).

Ejemplo de configuración en Apache: 
<VirtualHost *:80>
    ServerName linux-ub
    ServerAdmin webmaster@linux-ub
    DocumentRoot /var/www/newWebsite
    ErrorLog ${APACHE_LOG_DIR}/error newWebsite.log
    CustomLog ${APACHE_LOG_DIR}/access newWebsite.log combined
</VirtualHost>
Este fragmento define un host virtual en Apache, especificando el nombre del servidor, el directorio raíz del sitio y los archivos de registro.

8 Plex Media Server: multimedia con ecosistema propio

¿Qué es? Plex Media Server es una plataforma para organizar y transmitir contenido multimedia personal a dispositivos compatibles.

¿Cómo funciona? Su objetivo es similar al de Jellyfin: centralizar la biblioteca audiovisual y facilitar su reproducción desde diferentes lugares y dispositivos.

Analogía: Plex es como un servicio de streaming personal: organiza tu contenido y lo presenta con una interfaz cuidada, similar a la de las plataformas comerciales.

¿Qué puedes hacer con Plex?

  • Organizar películas, series, música y fotografías.
  • Mostrar carátulas e información del contenido.
  • Acceder a la biblioteca desde aplicaciones compatibles.
  • Compartir bibliotecas con otros usuarios, según la configuración y las funciones disponibles.

Ventajas

  • Interfaz visual cuidada.
  • Aplicaciones para diferentes dispositivos.
  • Administración centralizada del contenido.
  • Configuración relativamente accesible para usuarios domésticos.

Desventajas

  • Algunas funciones dependen de un plan de pago o de condiciones comerciales que pueden cambiar.
  • El acceso remoto puede requerir configuración adicional.
  • La transcodificación puede consumir bastantes recursos del equipo.
Ejemplo práctico: Instala Plex Media Server en tu PC, selecciona las carpetas de películas y accede a la biblioteca desde un televisor o teléfono compatible.

9 VirtualBox: crear máquinas virtuales para experimentar

¿Qué es? VirtualBox es un programa de virtualización que permite ejecutar máquinas virtuales dentro de un ordenador físico.

¿Cómo funciona? Una máquina virtual funciona como un ordenador independiente, con su propio sistema operativo y sus aplicaciones, aunque comparte los recursos físicos del equipo anfitrión.

Analogía: VirtualBox es como tener varios ordenadores dentro de uno solo: puedes experimentar con diferentes sistemas operativos sin riesgo para tu equipo principal.

¿Qué puedes hacer con VirtualBox?

  • Instalar Linux sin eliminar Windows.
  • Probar diferentes sistemas operativos.
  • Experimentar con configuraciones de red.
  • Aprender a administrar servidores en un entorno de pruebas.
  • Crear laboratorios para practicar antes de modificar un servidor real.

Ventajas

  • Permite experimentar sin dedicar un ordenador físico a cada sistema.
  • Facilita las pruebas de diferentes configuraciones.
  • Es útil para aprender administración de sistemas.
  • Permite utilizar instantáneas en determinadas configuraciones para regresar a estados anteriores.

Desventajas

  • Las máquinas virtuales consumen RAM, procesador y almacenamiento.
  • El rendimiento depende del hardware disponible.
  • La configuración de redes virtuales puede resultar compleja al principio.
  • Una máquina virtual no sustituye a las copias de seguridad de los datos.
Ejemplo práctico: Si tienes un PC con Windows, puedes crear una máquina virtual con Ubuntu Server y utilizarla para practicar la instalación de Apache o Samba sin modificar el sistema principal.

Explora

Nivel 5 — Transferencia y buenas prácticas

12 Recomendaciones antes de instalar cualquier programa

Antes de convertir tu PC en servidor, conviene seguir estas recomendaciones:

  1. Descarga el software desde su sitio oficial. Evita instaladores de procedencia desconocida.
  2. Comprueba los requisitos. Verifica la compatibilidad con tu sistema operativo y arquitectura.
  3. Empieza en una red local. Es más sencillo probar el funcionamiento antes de permitir conexiones desde Internet.
  4. Protege los datos. Conserva copias de seguridad de los archivos importantes.
  5. Configura los permisos. Cada usuario debe tener únicamente el acceso que necesita.
  6. Mantén el sistema actualizado. Instala las actualizaciones de seguridad del sistema operativo y de las aplicaciones.
  7. No abras puertos innecesarios. Publicar un servicio en Internet requiere evaluar los riesgos y configurar el acceso de forma segura.
Resumen del capítulo: Existen muchas herramientas para convertir un PC en servidor, y cada una responde a una necesidad diferente.
  • XAMPP facilita el desarrollo web local.
  • CasaOS simplifica la administración de aplicaciones domésticas.
  • Docker permite ejecutar aplicaciones en contenedores.
  • Jellyfin y Plex sirven para gestionar bibliotecas multimedia.
  • Samba y File Browser facilitan compartir y administrar archivos.
  • Apache y Nginx permiten alojar páginas web.
  • VirtualBox es útil para aprender y experimentar con sistemas operativos.
Recomendación para empezar: Si tienes un ordenador antiguo y quieres crear un servidor doméstico, instala una distribución Linux compatible y comienza con un solo servicio. Si prefieres compartir películas, prueba Jellyfin; si quieres compartir documentos, considera Samba; y si quieres aprender a alojar páginas web, comienza con Apache o XAMPP en un entorno local.
Reto integrador

Diseña tu servidor ideal

🌐 Contexto

Tu institución educativa ha recibido un ordenador antiguo pero funcional. El rector te ha pedido que lo conviertas en un servidor para mejorar los servicios digitales del colegio. Tienes libertad para decidir qué servicios implementar, pero debes justificar cada elección técnica, considerar la seguridad y presentar un plan de implementación.

🎯 Objetivo

Diseñar una propuesta completa para convertir ese ordenador en un servidor funcional que resuelva al menos dos necesidades reales de tu institución (por ejemplo: compartir archivos, alojar una página web, transmitir contenido multimedia, etc.).

📋 ¿Qué debes lograr?

  • Seleccionar al menos dos programas de los estudiados (XAMPP, CasaOS, Docker, Jellyfin, Samba, File Browser, Apache, Nginx, Plex, VirtualBox).
  • Justificar cada elección con argumentos técnicos, comparando ventajas y desventajas.
  • Diseñar un diagrama o esquema de cómo se integrarían los servicios en el servidor.
  • Definir un plan de seguridad básico: permisos, contraseñas, actualizaciones, copias de seguridad.
  • Estimar los recursos necesarios: almacenamiento, RAM, procesador.
  • Presentar una conclusión sobre la viabilidad del proyecto y los beneficios esperados.

⚠️ Restricciones

  • No puedes usar más de tres programas diferentes.
  • Debes considerar que el ordenador tiene recursos limitados (ejemplo: 4 GB de RAM, 500 GB de disco).
  • El servidor debe funcionar en una red local escolar sin acceso a Internet inicialmente.
  • Debes incluir al menos una medida de seguridad por cada servicio implementado.

✅ Criterios de éxito

  • Comprensión: Explicas correctamente qué hace cada programa y por qué lo elegiste.
  • Aplicación: Los servicios propuestos son coherentes con las necesidades planteadas.
  • Funcionalidad: El diseño es viable con los recursos disponibles.
  • Creatividad: Propones soluciones originales o combinaciones interesantes.
  • Calidad técnica: Los argumentos son precisos y están bien fundamentados.
  • Argumentación: Justificas cada decisión con razones técnicas claras.
  • Buenas prácticas: Incluyes medidas de seguridad, permisos y copias de seguridad.
