Objetivo de aprendizaje

¿Qué lograrás en este taller?

Analizar y seleccionar sistemas operativos y programas para servidores, comparando alternativas como Windows Server, Ubuntu Server, Debian, Rocky Linux, CasaOS, Proxmox VE, XAMPP, Docker, Jellyfin, Plex, Samba, Apache, Nginx y VirtualBox, aplicando criterios técnicos, de licencia, recursos y seguridad, para diseñar una propuesta de servidor doméstico o educativo que responda a una necesidad real, demostrando responsabilidad, pensamiento crítico y buenas prácticas de administración.

Activación

Un computador olvidado en el aula

En tu colegio hay un computador de escritorio que ya nadie usa porque es "lento". Tu docente de Informática te comenta que podría servir para algo más que para abrir un navegador: podría convertirse en un servidor para compartir archivos, alojar la página web del curso o transmitir videos educativos a los celulares de tus compañeros.

El problema es que no sabes por dónde empezar: ¿Windows o Linux? ¿Qué programa instalar? ¿Será seguro? ¿Y si daña el computador? Mientras lo piensas, recuerdas que en internet hay decenas de tutoriales que dicen cosas diferentes.

¿Qué decisión tomarías tú para transformar ese computador en un servidor útil sin gastar dinero y sin arriesgar la información del colegio?

Fundamentos

Conceptos básicos y conocimientos previos

¿Qué es un sistema operativo de servidor? Concepto base

+
¿Qué es?

Un sistema operativo es el software que administra los recursos de un ordenador y permite ejecutar programas. En un servidor, gestiona el procesador, la memoria, el almacenamiento, la red y los servicios que utilizan otros dispositivos.

¿Cómo funciona?

Actúa como intermediario entre el hardware y las aplicaciones. Cuando otro equipo solicita un archivo o una página web, el sistema operativo del servidor recibe la petición, la procesa y devuelve la respuesta.

Analogía

Es como el director de una biblioteca: no escribe los libros, pero organiza los recursos, controla quién entra y asegura que cada visitante encuentre lo que busca.

Recomendación Antes de instalar un sistema operativo de servidor, verifica la compatibilidad del hardware y descarga la imagen desde la fuente oficial.

Diferencia entre sistema operativo, software de servidor y plataforma de administración Distinción clave

+
¿Qué es?

Sistema operativo: administra el ordenador y permite ejecutar programas (Windows Server, Ubuntu Server, Debian).
Software de servidor: proporciona un servicio específico, como alojar páginas web o compartir archivos (Apache, Samba, Jellyfin).
Plataforma de administración: facilita la instalación y gestión de varios servicios, a menudo mediante interfaz gráfica o web (CasaOS, Proxmox VE).

Ejemplo

Puedes instalar Ubuntu Server en tu PC, utilizar Docker para ejecutar aplicaciones y administrar algunos servicios mediante CasaOS. Cada pieza cumple un rol diferente.

Error frecuente Confundir una plataforma de administración como CasaOS con un sistema operativo completo. CasaOS se instala sobre una distribución Linux compatible.

Comprensión

Relaciones entre conceptos y funcionamiento

Windows como servidor: Windows Server y Windows de escritorio Sistema operativo

+
¿Qué es?

Windows es una familia de sistemas operativos desarrollada por Microsoft. Existen versiones para ordenadores personales y ediciones específicas para servidores. Windows Server está orientado a administrar servicios de red, usuarios, aplicaciones y recursos compartidos.

Características principales
  • Administración de usuarios y permisos.
  • Compartición de archivos e impresoras.
  • Integración con Active Directory Domain Services.
  • Compatibilidad con virtualización Hyper-V, según la edición.
  • Administración mediante herramientas gráficas y PowerShell.
  • Funciones de seguridad y gestión para entornos empresariales.
Windows de escritorio

También puedes utilizar un PC con Windows para crear servidores web, compartir archivos, transmitir multimedia o ejecutar un servidor de juegos. Sin embargo, no sustituye todas las funciones de Windows Server y las condiciones de licencia pueden limitar su uso.

Ventajas
  • Interfaz gráfica familiar para muchos usuarios.
  • Compatibilidad con numerosos programas comerciales.
  • Administración relativamente sencilla para tareas habituales.
  • Integración con herramientas y servicios de Microsoft.
Desventajas
  • Las licencias de algunas ediciones y funciones pueden tener costes.
  • Puede consumir más recursos que una instalación Linux ligera.
  • Las actualizaciones pueden requerir reinicios.
  • Algunas herramientas avanzadas están vinculadas a ediciones concretas.
¿Cuándo elegir Windows? Si necesitas ejecutar aplicaciones que dependen de Windows, administrar una red basada en tecnologías Microsoft o trabajar en un entorno que ya utiliza este sistema.

Linux como servidor: distribuciones y características Sistema operativo

+
¿Qué es?

Linux es una familia de sistemas operativos basados en el kernel Linux. Se distribuye mediante diferentes distribuciones que incorporan herramientas, gestores de paquetes y configuraciones específicas. Es muy utilizado en servidores web, servicios de red, infraestructura en la nube y almacenamiento.

Características principales
  • Puede utilizarse sin coste de licencia en numerosas distribuciones.
  • Ofrece herramientas de administración mediante terminal.
  • Dispone de una amplia variedad de programas para servidores.
  • Permite automatizar tareas mediante scripts.
  • Facilita la configuración de servicios y permisos.
  • Cuenta con una gran comunidad y abundante documentación.
Desventajas
  • Algunas tareas requieren aprender comandos de terminal.
  • Ciertos programas comerciales solo están disponibles para Windows.
  • La configuración de servicios puede exigir conocimientos de redes y permisos.
  • Las instrucciones varían entre distribuciones y versiones.
¿Cuándo elegir Linux? Si quieres aprender administración de servidores, reutilizar un PC antiguo, ejecutar aplicaciones de código abierto o construir un servidor doméstico con control sobre los servicios instalados.

Distribuciones Linux recomendadas para principiantes Aplicación

+
Ubuntu Server

Opción popular para principiantes y administradores. Cuenta con documentación amplia y permite instalar servicios como Apache, Nginx, Samba y Docker. Ideal para servidores web, aplicaciones y aprendizaje de administración Linux.

Debian

Distribución conocida por su estabilidad y por ofrecer un amplio repositorio de paquetes. Ideal para servidores domésticos, servicios de red y equipos que deben funcionar durante largos periodos.

Rocky Linux

Distribución orientada a entornos empresariales y compatible con el ecosistema de Red Hat Enterprise Linux. Ideal para aprender administración de servidores y trabajar con software habitual en entornos empresariales.

Linux Mint

Distribución de escritorio útil si deseas conservar una interfaz gráfica familiar mientras aprendes Linux. No es una distribución especializada en servidores.

CasaOS y Proxmox VE

CasaOS es una plataforma de administración para servidores domésticos que facilita la instalación y gestión de aplicaciones mediante una interfaz web. Proxmox VE es una plataforma basada en Debian que permite administrar máquinas virtuales y contenedores desde una interfaz web.

Ejemplos y procedimientos

XAMPP: crear un servidor web local Programa

+
¿Qué es?

XAMPP es un paquete de software que facilita la instalación de un entorno de desarrollo web. Incluye Apache, MariaDB, PHP y otras herramientas. Es útil para aprender cómo funciona un servidor web sin instalar cada componente por separado.

¿Qué puedes hacer?
  • Crear páginas web y probarlas desde el navegador.
  • Desarrollar aplicaciones con PHP.
  • Utilizar bases de datos MariaDB.
  • Probar proyectos web antes de publicarlos.
  • Permitir acceso desde otros dispositivos de tu red.
Ejemplo práctico

Instala XAMPP en Windows, inicia Apache y coloca los archivos de tu página en el directorio htdocs. Después, abre http://localhost/ en el navegador para probarla.

Desventaja No es la mejor opción como plataforma predeterminada para un servidor público de producción. Una configuración insegura puede exponer bases de datos y herramientas administrativas.

Docker: ejecutar aplicaciones en contenedores Programa

+
¿Qué es?

Docker es una plataforma que permite empaquetar y ejecutar aplicaciones en contenedores. Un contenedor incluye la aplicación y sus dependencias, lo que facilita su instalación y despliegue en entornos compatibles. A diferencia de una máquina virtual tradicional, comparte el kernel del sistema operativo anfitrión.

¿Qué puedes hacer?
  • Ejecutar varias aplicaciones en un mismo servidor.
  • Separar los entornos de diferentes servicios.
  • Reproducir configuraciones de forma más consistente.
  • Actualizar o sustituir aplicaciones con mayor facilidad.
  • Ejecutar servicios como Jellyfin, servidores web y bases de datos.
Ventajas y desventajas

Ventajas: facilita la instalación y administración, permite aislar servicios, favorece la portabilidad y cuenta con un amplio ecosistema de imágenes.
Desventajas: requiere aprender conceptos como imágenes, contenedores, volúmenes y redes; los datos importantes deben almacenarse de forma persistente; una configuración incorrecta puede exponer servicios.

Ejemplo práctico

Puedes utilizar Docker Compose para definir una aplicación y sus servicios relacionados en un archivo de configuración, y después iniciarlos conjuntamente.

Jellyfin y Plex: servidores multimedia personales Programa

+
Jellyfin

Sistema multimedia gratuito y de código abierto que permite organizar y transmitir contenido personal desde un servidor a diferentes dispositivos. Puedes organizar una biblioteca, reproducir contenido desde un navegador o aplicación, crear usuarios y administrar el acceso.

Plex Media Server

Plataforma para organizar y transmitir contenido multimedia personal a dispositivos compatibles. Su objetivo es similar al de Jellyfin: centralizar la biblioteca audiovisual y facilitar su reproducción desde diferentes lugares.

File Browser, Samba, Apache y Nginx Programa

+
File Browser

Proporciona una interfaz web para navegar por carpetas y administrar archivos. Útil si quieres acceder a documentos desde distintos dispositivos utilizando un navegador.

Samba

Implementa servicios de archivos e impresión compatibles con SMB, lo que facilita compartir recursos entre sistemas Linux y equipos Windows. Es adecuado cuando quieres que las carpetas aparezcan como recursos de red en el explorador de archivos.

Apache HTTP Server

Servidor web ampliamente utilizado que permite entregar páginas y ejecutar configuraciones para diferentes tipos de sitios web. Resulta útil para aprender alojamiento web y desplegar aplicaciones compatibles.

Nginx

Servidor web y proxy inverso. Permite alojar páginas web y distribuir solicitudes entre varios servidores. Es gratuito en su edición de código abierto.

# Ejemplo de configuración de Apache
ServerName www.ejemplo.com
ServerAdmin webmaster@ejemplo.com
DocumentRoot /var/www/miSitio
ErrorLog ${APACHE_LOG_DIR}/error.log
CustomLog ${APACHE_LOG_DIR}/access.log combined
¿Cuál conviene utilizar? File Browser es buena alternativa cuando prefieres administrar archivos desde una interfaz web. Samba resulta más adecuado cuando quieres que las carpetas aparezcan como recursos de red en el explorador de archivos.

VirtualBox: crear máquinas virtuales para experimentar Programa

+
¿Qué es?

Programa de virtualización que permite ejecutar máquinas virtuales dentro de un ordenador físico. Una máquina virtual funciona como un ordenador independiente, con su propio sistema operativo y aplicaciones, aunque comparte los recursos físicos del equipo anfitrión.

¿Qué puedes hacer?
  • Instalar Linux sin eliminar Windows.
  • Probar diferentes sistemas operativos.
  • Experimentar con configuraciones de red.
  • Aprender a administrar servidores en un entorno de pruebas.
  • Crear laboratorios para practicar antes de modificar un servidor real.
Ejemplo práctico

Si tienes un PC con Windows, puedes crear una máquina virtual con Ubuntu Server y utilizarla para practicar la instalación de Apache o Samba sin modificar el sistema principal.

Desventaja Las máquinas virtuales consumen RAM, procesador y almacenamiento. El rendimiento depende del hardware disponible y una máquina virtual no sustituye a las copias de seguridad.

Recomendaciones antes de instalar cualquier programa Buenas prácticas

+
  • Descarga el software desde su sitio oficial. Evita instaladores de procedencia desconocida.
  • Comprueba los requisitos. Verifica la compatibilidad con tu sistema operativo y arquitectura.
  • Empieza en una red local. Es más sencillo probar el funcionamiento antes de permitir conexiones desde Internet.
  • Protege los datos. Conserva copias de seguridad de los archivos importantes.
  • Configura los permisos. Cada usuario debe tener únicamente el acceso que necesita.
  • Mantén el sistema actualizado. Instala las actualizaciones de seguridad del sistema operativo y las aplicaciones.
  • No abras puertos innecesarios. Publicar un servicio en Internet requiere evaluar riesgos y configurar el acceso de forma segura.
Recomendación Si tienes un ordenador antiguo y quieres crear un servidor doméstico, instala una distribución Linux compatible y comienza con un solo servicio.

¿Qué sistema operativo y programa elegir según tus necesidades? Toma de decisiones

+
Guía rápida
  • Quiero alojar una página web: XAMPP para aprender desarrollo local, o Apache/Nginx para un servidor web más configurable.
  • Quiero compartir archivos: Samba para la red local, o File Browser para administrarlos desde un navegador.
  • Quiero ver películas y series: Jellyfin si buscas una solución gratuita y de código abierto, o Plex si prefieres su ecosistema.
  • Quiero ejecutar varias aplicaciones: Docker para gestionar contenedores. CasaOS puede facilitar su administración web.
  • Quiero aprender sin modificar mi PC principal: VirtualBox para instalar un sistema operativo de servidor en una máquina virtual.

Reto integrador

Diseña el servidor del aula

Contexto

Tu colegio tiene un computador antiguo con 4 GB de RAM y un disco duro de 500 GB. El docente de Informática quiere convertirlo en un servidor para el aula. Los estudiantes necesitan:

  • Compartir archivos de proyectos entre compañeros.
  • Alojar la página web del curso.
  • Ver videos educativos desde sus celulares.

¿Qué debes lograr?

1. Elige el sistema operativo

Justifica si usarás Windows Server, Ubuntu Server, Debian u otra opción.

2. Selecciona los programas

Elige al menos tres herramientas para cubrir las necesidades del aula.

3. Define la seguridad

Indica cómo protegerás los archivos y evitarás accesos no autorizados.

4. Explica la instalación

Describe los pasos generales para poner en marcha el servidor.

Criterios de éxito

  • Coherencia entre las necesidades y las herramientas elegidas.
  • Justificación técnica basada en el contenido del taller.
  • Consideración de licencias, recursos y seguridad.
  • Claridad en la explicación de los pasos.
  • Creatividad en la solución propuesta.
